# Oil Management 2.0 — экономический симулятор нефтяной компании

Браузерная игра для **iPhone (Safari, режим «На экран „Домой“»)** и **компьютера**. Без сервера, без сборки, без внешних библиотек — чистые HTML/CSS/JS, работает прямо на GitHub Pages и офлайн.

Старт: **1 января 2000 года**, название компании и месторождения — любое своё (меняется и в «Настройках»), 11 скважин со станками-качалками, небольшой ЦКППН, 3 млрд ₸. Цель — выполнять планы добычи, расти и войти в ТОП-10 компаний региона.

> Все компании, месторождения, покупатели и подрядчики вымышлены. Цены на нефть и курс 2000–2026 гг. приблизительно повторяют реальную динамику (кризисы 2008, 2014–2015, 2020).

## Как опубликовать на GitHub Pages

1. Создайте репозиторий (или откройте существующий) на GitHub.
2. Загрузите **всё содержимое этой папки в корень** репозитория (`index.html` должен лежать в корне). Через сайт: *Add file → Upload files* → перетащите файлы и папки `css`, `js`, `assets`, `tests`.
3. *Settings → Pages → Build and deployment → Source: Deploy from a branch*, ветка `main`, папка `/ (root)` → *Save*.
4. Через 1–2 минуты игра будет доступна по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

### Установка на iPhone 15
Откройте адрес в **Safari** → кнопка «Поделиться» → **«На экран „Домой“»**. Игра запустится на весь экран как приложение, с иконкой и работой без интернета (после первого открытия).

### Обновление версии
При изменении файлов увеличьте номер версии `?v=2.0.0` в `index.html` и `CACHE` в `sw.js` — тогда телефоны гарантированно получат новую версию.

## Структура

```
index.html              точка входа
manifest.webmanifest    PWA-манифест (иконка, полноэкранный режим)
sw.js                   офлайн-кэш (сначала сеть, потом кэш)
css/style.css           стили: мобильная раскладка + десктоп
js/data.js              справочники: должности, материалы, объекты, подрядчики, технологии, рынок, цели
js/engine.js            движок симуляции (без DOM, детерминированный, тестируемый в Node)
js/charts.js            SVG-графики, 2D-анимации оборудования и анимированные лица
js/sound.js             звуки (Web Audio, синтез без аудиофайлов) и фоновый шум промысла
js/app.js               интерфейс: вкладки, дашборды, модальные окна, прокрутка времени
assets/                 логотип и иконки
tests/engine.test.js    48 автотестов движка
tests/fuzz.js           стресс-бот: случайная игра на сотни лет с проверкой инвариантов
tests/indicators.js     проверка всех индикаторов: «живые» значения и сверки
```

Проверка: `node tests/engine.test.js`, `node tests/fuzz.js` и `node tests/indicators.js` (Node.js 18+).

## Вкладки игры

| Вкладка | Что внутри |
|---|---|
| **Сводка** | KPI с цветовыми индикаторами, спидометры плана и доверия, живая технологическая схема, список «Требует внимания», цели, события |
| **Добыча → Цеха** | Четыре цеха ЦДНГ-1…4 с карточками начальников (коэффициент эффективности К, лояльность, замечания, выговоры, премии, увольнение/найм).  Годовой план/факт по ЦДНГ, кнопка «Изменить план» (свой объём по каждому цеху), помесячная таблица отклонений (зелёный / жёлтый / красный), графики по месяцам и нарастающим итогом |
| **Добыча → Скважины** | Фонд с анимированными СК/ЭЦН, фильтры, дебит, обводнённость, износ; ПРС, КРС, ОПЗ, ГРП, пуск/остановка |
| **Добыча → Пласт и ППД** | Пластовое давление, компенсация отбора закачкой (ползунок), запасы, сейсморазведка |
| **Подготовка** | Схема скважины → АГЗУ → УПСВ → техн. РВС → печи → отстойники/ЭДГ → товарные РВС → перекачка; вода → БКНС → нагнетательные. Режим: температура печей, дозировка деэмульгатора, промывка → группа качества нефти. Резервуары с анимацией налива. Оборудование и ТО |
| **ЦДПиТГ** | Цех добычи, подготовки и транспортировки газа. **Схема**: природный газ — газовые скважины → манифольд М-100 → входной сепаратор ВС → теплообменник «газ-газ» → ТГР → редуцирование 5,9→1,5 МПа (охлаждение до −20°C) → низкотемпературный сепаратор НС → БИР (учёт) → газопровод; контур ДЭГ (БРД → ТО/ТГР → НС → регенерация с котлом КТ-100); попутный газ — ЦКППН → сепаратор С-2 → МКС (0,2→0,9 МПа) → газопровод, излишки на факел. **УППГ**: подача ДЭГ и температура регенерации → концентрация ДЭГ и точка росы (норма: зимой ≤ −20°C, летом ≤ −10°C); газ не по норме — цена −30% и риск гидратной пробки. **МКС и ПНГ**: баланс попутного газа, аварийные остановы МКС. **Скважины**: 5 законсервированных газовых скважин на старте, расконсервация, бурение новых, аварии (порыв шлейфа, пропуск арматуры), ремонт. **Баланс**: добыча и сдача газа по месяцам, выручка |
| **НПЗ** | Модель НПЗ по установкам: **ЭЛОУ-АТ** (обессоливание: температура и промывка → соли и вода; печь П-1: температура → отбор светлых, перегрев — коксование; колонна К-1/К-2: газ, нафта, дизель, мазут; профиль отбора 160/180/200°C), **вакуумный блок** (ВГО + гудрон), **каталитический риформинг** (температура → октан и выход, водород, старение катализатора и регенерация), **гидроочистка** (температура, водород, катализатор → сера в ДТ и класс К2–К5), **каткрекинг** (температура → конверсия, бензин, СУГ, лёгкий газойль), **битумная** (летом выгодно, зимой лучше выключить). Материальный баланс сходится до тонны, топливо печей — из сухого газа и мазута. **Схема** с живыми потоками, **Показатели**: глубина, выход светлых, индекс Нельсона, ОЧ, сера, соли (стрелочные приборы), материальный баланс, паспорт качества, загрузка установок, графики за 90 дней. **Режим**: все температуры и параметры с прогнозом. **Установки**: строительство, износ, катализаторы. **Продукты**: парк и РВС НПЗ. **Компаундирование**: из пула выпускаются АИ-98, АИ-95 и АИ-92 по заданным долям, если хватает октана. **Задвижки отгрузки** бензина, дизеля, мазута и битума — кликабельные на схеме: закрытая задвижка копит продукт в парке. **Ремонты**: текущий (+30% ресурса, 4 сут) и капитальный (100%, 20 сут), авторемонт; износ выше 75% — аварийные остановки. Цена зависит от качества: АИ-80 −10%; ДТ К4 −4%, К3 −10%, К2 −15% |
| **АЗС** | Каждая станция: поток машин (город/трасса/посёлок), колонки ТРК (очередь при перегрузке), свои резервуары АИ-92 и ДТ (запас в днях), средний налив, магазин, кафе, мойка, улучшения. Анимированная станция с машинами, бензовозом и уровнем топлива. **Логистика**: парк НПЗ → бензовозы (свои или наёмные) → АЗС, докупка на рынке. В рознице только АИ-92+ и ДТ не ниже К4. **Цены**: наценка, маржа ₸/л по АИ-92/95/98 и ДТ, таблица эластичности спроса. **Финансы**: отчёт о прибыли сети (выручка, себестоимость, акциз, магазин, персонал, аренда, доставка, EBITDA) за месяц и прошлый месяц, рентабельность, маржа на литр, структура продаж, графики по месяцам, рейтинг станций. Ремонт станций: текущий (2 сут) и капитальный (7 сут); изношенная АЗС теряет клиентов |
| **Быт** | Вахтовый посёлок: общежития (120 койко-мест), столовая (80 мест в две смены), спортзал (тренажёрный зал, бильярд), клуб. Живут в посёлке только вахтовики; НПЗ, АЗС и офис АУП — местные (живут дома, питание по талонам). Меню на доске: сухой паёк / горячее питание (завтрак, обед, ужин) / усиленное. Нехватка мест — съём жилья и падение морали, изношенная столовая — отравления и штраф Санэпиднадзора |
| **Смены 24/7 (НПЗ, АЗС)** | 4 бригады по 12 ч (день/ночь, 2 через 2), ночные +50%. 3 бригады — сверхурочные ×1,5 и усталость, 2 — 12/12 без выходных, 1 — НПЗ вынужденно останавливается, АЗС работает только днём (минус ночные продажи 10–30%). К пуску НПЗ/АЗС операторы набираются на 4 бригады. Табло смен на вкладках НПЗ → Схема и АЗС → Сеть |
| **Безопасность** | НПЗ → Безопасность: промышленная (экспертиза ПБ всех опасных объектов), пожарная, БиОТ. СБ (служба безопасности) — на вахте, охраняет промысел: меньше людей — кражи кабеля и врезки. Охранная фирма на НПЗ (5 млн ₸/мес) и АЗС (0,6 млн ₸/мес за станцию): без неё хищения с парка НПЗ и ночные ограбления АЗС |
| **НПЗ и АЗС — отдельные объекты** | Свои вкладки «Персонал», «Энергия», «Снабжение». Штат: операторы (смены), лаборанты НПЗ (паспорт качества; < 50% — опт −5%), слесари НПЗ (< 50% — износ быстрее, ремонт ×1,5), управляющие АЗС (без них недостачи топлива и −15% магазина). Энергия — свой фидер, оплачивается отдельно, не зависит от энергетики промысла. Ремонт расходует запчасти: НПЗ 1/3 компл, ТРК 1/2 компл; ЗИП к пуску в подарок. Пожарная автоцистерна НПЗ обязательна (иначе штраф Промбезопасности). Бензовозы АЗС — во вкладке «Снабжение» |
| **ИТР НПЗ и АЗС** | Реальная цепочка: директор НПЗ → главный инженер → главные технолог, механик, энергетик, метролог, нач. лаборатории, инженеры ПБ/ОТ и ПТО → начальники смен, мастер энергетики → операторы, слесари, электромонтёры, КИПиА, лаборанты. Службы НПЗ (Управление, Технология, Механика, Энергетика, КИПиА, Лаборатория, Промбезопасность) влияют на мощность (до −15%), износ, отключения питания, перерасход энергии, аварии и штрафы. АЗС: начальник сети → инженер-механик, управляющий на каждую станцию → техники ТРК, электромонтёры, операторы |
| **Ремонт и склад НПЗ/АЗС** | Вкладки «Ремонт» и «Склад» у каждого объекта. Авторемонт (тумблер): порог текущего ремонта и капремонта по износу, сколько объектов одновременно; берёт ЗИП со своего склада, при нехватке денег или ЗИП — запись в журнал. Склад НПЗ: ЗИП, реагенты ЭЛОУ (без них хуже обессоливание и коррозия), присадки (без них опт −3%). Склад АЗС: ЗИП ТРК, фильтры и пистолеты (без них износ колонок ×1,5 и −5% клиентов). Своя автозакупка: заказ при остатке меньше срока поставки + неделя, пополнение до 15–90 сут запаса |
| **Вкладки НПЗ и АЗС** | Сгруппированы, всё помещается в одну строку. НПЗ: Схема · Производство (Показатели, Режим, Продукты) · Установки (Состав, Ремонт) · Обеспечение (Персонал, Энергия, Склад, Безопасность). АЗС: Сеть · Станции · Торговля (Финансы, Цены) · Обеспечение (Персонал, Энергия, Ремонт, Склад). Внутри группы — второй ряд; группа помнит последнюю открытую вкладку |

Флаги стран, требования к качеству по эпохам (ГОСТ 305 → К4/К5), индикатор план/факт с отметкой «план на сегодня», баланс выпуск/обязательства, нетбэк в сравнении со спот-оптом. Отгрузка по договорам идёт раньше спота; недопоставка более 5% — штраф |
| **Общий «Персонал»** | Только промысел: добыча, подготовка, ремонт, службы, СБ. Штат НПЗ и АЗС — отдельно в их вкладках «Обеспечение → Персонал» (кнопки-переходы вверху общего списка) |
| **Пуск/останов НПЗ** | Пульт на вкладке НПЗ → Схема и задвижка сырья на линии РВС → ЭЛОУ: останов 1 сутки (40%), пуск 3 суток (30 → 60 → 90%) за 4 млн ₸, каждый останов −1,5% ресурса установок. Термометр печи, лампы РАБОТА / ПУСК / ОСТАНОВ / СТОП |
| **Мнемосхема СУГ** | ГФУ и НПЗ → задвижки → ёмкости → задвижки → АЗС и опт; на линиях — потоки за сутки, у ёмкостей — накопление и через сколько суток заполнятся. Закрытая ГФУ отсекается, СУГ НПЗ при закрытой задвижке идёт в топливную сеть завода |
| **СУГ (ЦДПиТГ → СУГ)** | ГФУ стоит после МКС (без МКС и ёмкостей не построить): из сжатого попутного газа извлекает пропан-бутан (≈0,28 кг/м³), сухой газ — в газопровод. На НПЗ СУГ дают ЭЛОУ-АТ (головка стабилизации ≈1,1% нефти) и каткрекинг. Хранение — только в построенных ёмкостях (+100 т). Полные ёмкости при закрытом опте: ГФУ разгружается, газ НПЗ уходит в топливную сеть завода вместо мазута — жидкий СУГ на факеле не жгут. Ёмкости, ГФУ и газовые колонки — опасные объекты: освидетельствование сосудов раз в 4 года, утечки и пожары, штрафы Комитета промбезопасности |
| **Автопарк** | Спецтехника (подъёмники ПРС, цементировочные агрегаты, автоцистерны, ППУ, автокран) и легковой транспорт (вахтовые автобусы, легковые). Заправка своим дизелем (тумблер): техника и ДГУ берут ДТ со своих АЗС, затем из парка НПЗ, потом со склада ГСМ |
| **Акции** | Оценка компании и цена акции, IPO (10–30%) на вымышленной бирже при капитализации от 25 млрд ₸, котировки с настроением рынка, P/E, дивиденды (доверие совета и цена акций), обратный выкуп, допэмиссия раз в год. **Биржа**: акции 40 крупнейших компаний рейтинга, свой портфель, доходность и дивиденды ≈4% годовых |

Фильтры: предпенсионеры, молодёжь, недовольные, по подразделению |

## Ключевые механики

- **Технологическая цепочка с узкими местами.** Каждый день движок подбирает максимально возможную загрузку промысла: если переполнены товарные, технологические или водяные РВС, не хватает мощности УПСВ/ЦКППН/БКНС или электроэнергии — добыча автоматически ограничивается, и игра показывает причину.
- **Пласт.** Давление падает при отборе и восстанавливается закачкой воды (подтоварная + водозабор). Перекомпенсация >105% ускоряет обводнение. Запасы истощаются, сейсморазведка может их прирастить.
- **Скважины.** Потенциал, обводнённость (растёт со временем), износ, случайные отказы (насос, штанги, НКТ, привод, ЭЦН, кабель) с разными материалами для ремонта.
- **Качество нефти** (вода, соли → I/II/III группа или некондиция) влияет на цену и допуск к договорам.
- **План/факт.** В начале года — выбор плана (консервативный / базовый / амбициозный) или **свой план** по каждому ЦДНГ (50–200% прогноза). План можно скорректировать в любой момент на вкладке «Добыча → Цеха»: прошедшие месяцы не меняются, остаток распределяется по дням; корректировка после января стоит −3 доверия. Утверждённый план не меняется до 31 декабря: новые скважины дают сверхплановую добычу. Выполнение влияет на доверие совета директоров.
- **Цеха и начальники.** Скважины разделены на ЦДНГ-1…4. У каждого цеха начальник с коэффициентом эффективности К (0,6–1,35): он влияет на добычу цеха и частоту отказов. После каждого месяца — окно «Итоги по цехам» (план, факт, отклонение, отказы, простой) с решениями: премия, замечание, выговор, увольнение, найм из трёх кандидатов. Взыскание за провал плана временно повышает К, без оснований — портит лояльность и мораль; при лояльности <20% начальник может уйти сам; два выговора — увольнение без пособия. Показ отчёта отключается в «Настройках».
- **Кадры.** Зарплата начисляется каждому работнику: тариф должности × разряд (+8% за ступень) × надбавка за стаж (2% в год, до 25%). Эффективность людей растёт с опытом и обучением и влияет на работу подразделения. Пенсия: мужчины в 63, женщины в 58 (с 2018 г. +0,5 года ежегодно); при выходе — пособие, людей нужно заменять заранее. Недовольные работники могут уволиться сами; увольнение предпенсионера стоит 3 зарплаты и бьёт по морали.
- **Персонал и мораль**: нехватка людей снижает эффективность подразделений; низкая мораль ведёт к забастовкам.
- **Охрана труда и экология.** Несчастные случаи зависят от реальных факторов: укомплектованности службы ОТ, СИЗ на складе, износа оборудования, переработок, морали, культуры безопасности и медосмотров. Пострадавший уходит на больничный (подразделение работает слабее), компания выплачивает возмещение, при тяжёлых случаях — штраф и расследование. Госорганы (экология, промбезопасность, инспекция труда, пожарный надзор) проверяют фактическое состояние и выписывают штрафы с перечнем нарушений, повторные — ×1,5. Попутный газ: факел облагается платой за эмиссии (с 2006 г. ×6) и штрафами.
- **Финансы**: НДПИ, рентный налог на экспорт (зависит от Brent), налог на имущество, КПН 20% с переносом убытков, амортизация, аннуитетные кредиты.
- **События с выбором**: морозы, порывы, проверки, забастовки, покупка актива, кражи, рационализаторы, исторические события (кризис 2008, девальвации, пандемия и квоты ОПЕК+ 2020).
- **Конец игры**: три месяца с отрицательным балансом — банкротство; доверие совета 0 — отставка.

**Звук и анимации.** Звуки синтезируются в браузере (без файлов): кнопки, тик дня, перемотка, касса, тревога при авариях, фанфары за цели, стройка, найм/увольнение, события; фоновый гул насосов и скрип станков-качалок. Анимации: конфетти, тряска при аварии, бегущие цифры, всплывающий «±₸» после перемотки. Настройки — «Настройки → Звук и анимации». На iPhone звук включается после первого касания; в беззвучном режиме его не слышно.

**Сохранения.** Игра сохраняется автоматически после каждого действия, каждый игровой день и при сворачивании приложения; при следующем открытии сразу продолжается с той же даты и вкладки. Раз в игровой месяц создаётся резервная копия — если основное сохранение повредится, загрузится она. Есть 3 ручных слота сохранения. Экспорт в файл (на iPhone — через меню «Поделиться» в «Файлы») защищает от удаления приложения и переносит игру между устройствами; импорт — там же, в «Настройках».
